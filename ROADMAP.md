# Sight roadmap

Where Sight stands and what comes next. Plans can change; feedback from the beta helps decide
the order. Version numbers follow the development steps: `0.<milestone>.<step>`.

## Done

- **Foundation** (0.1) – the application window on Windows, Linux and macOS, canvas with page,
  grid, rulers, zoom and pan.
- **Core editor** (0.2) – shapes, selection, move/resize/rotate, snapping with smart guides,
  styles, text, copy/paste, undo/redo.
- **Connectors and stencils** (0.3) – glued, routed connectors with labels and arrowheads; 176
  shapes in stencil packs; SVG, PNG and JPEG images as shapes; ribbon and classic menus.
- **Documents** (0.4) – `.sight` files, autosave and crash recovery, pages, layers, export as SVG,
  PNG, JPEG and PDF.

## Now: beta

- Public beta: installers for all three systems, automatic updates, problem reports through
  GitHub issues, a first help page. First beta release: **0.4.13**.

## Planned

- **Automation** – a command-line tool and an API, so scripts and AI assistants can create and
  change diagrams with the same rules as the app.
- **Professional features** – curved connectors, align and distribute, groups and containers,
  templates, shape data, rich text, automatic layout, document themes.
- **Import** – draw.io diagrams and libraries, Mermaid flowcharts.
- **IT infrastructure** – port-level connections, device data (host name, IP, VLAN, …), rack
  diagrams.
- **Help** – built-in, searchable help that works offline, context help with F1, a getting-started
  tour.
- **Polish for 1.0** – performance with very large diagrams, signed installers on every system,
  release automation.
- **Browser edition** – Sight in the browser, with documents stored on a server.

Ideas and wishes: open an [issue](https://github.com/anneuf/Sight/issues/new/choose) (*Idea or wish*).
